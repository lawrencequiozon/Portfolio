# Mark Lawrence Portfolio

A personal portfolio website for Mark Lawrence Quiozon, built with Next.js and TypeScript. It presents his background, technical stack, featured project, learning focus, and contact information through an interactive single-page experience.

## Features

- Responsive portfolio layout
- Interactive terminal-style hero section
- About, education, technology stack, projects, services, and learning sections
- Featured CHIMS project showcase
- Animated boot screen, scroll progress, mouse glow, and profile card tilt effect
- Contact link via email

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- CSS
- Next Image

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

### Production

Create an optimized production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

## Project Structure

```text
app/
  globals.css   Global styles
  layout.tsx    Metadata and root layout
  page.tsx      Portfolio page and interactive components
public/         Images and other static assets
```
